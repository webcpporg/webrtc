== Changelog

What changed in webrtc in each version of webcpp, newest first, one line per
change. "Unreleased" is what the next version brings. The release notes of
every version are on webcpp's index page.

[#webrtc-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Added peer connections and data channels with the W3C's names, in Asio's
model.
* Added the native implementation over libdatachannel's C API, with
exceptions on and off.
* Added the browser implementation over the page's own `RTCPeerConnection`.
* Added a data channel's `ordered`, `max_packet_life_time`, `max_retransmits`,
`protocol` and `negotiated`.
* Added the unsupported policy natively; by default it refuses a
`max_packet_life_time` of 0.
* Added a runtime that holds libdatachannel's threads and caps connections.
* Added errors as values, in the category `webcpp.webrtc` and Asio's codes.
* Added the library's page, with its examples, guarantees and differences.
// end::unreleased[]
