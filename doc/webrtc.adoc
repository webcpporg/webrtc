= webrtc: WebRTC data channels in Asio's model
:toc: left
:toclevels: 1
:idprefix:
:sectanchors:
:example-caption!:
:attribute-missing: warn

webrtc is a header-only {cpp}20 library of peer connections and data
channels, one of the libraries of
https://github.com/webcpporg/webcpp[webcpp]. Its types and operations carry
the names and the shapes of the W3C's WebRTC API, `RTCPeerConnection` and
`RTCDataChannel`, and they are written in Asio's model: every operation takes
a completion token, runs its handler on the executor its object was made
with, and fails as a value. Natively it runs over libdatachannel; in the
browser, compiled with Emscripten, over the page's own objects, so that a
program is written once for both.

This page teaches webrtc section by section: two peers that talk, how a
program builds with it, the runtime, signalling, the events, the data
channels, the errors, cancellation and memory, what the native and the
browser implementations stand on, how it differs from the W3C's API, and
what it guarantees. Every program it shows is one of the library's examples, which
the build compiles, runs and compares with the output shown. The
<<reference,reference>> lists every name the headers declare.
